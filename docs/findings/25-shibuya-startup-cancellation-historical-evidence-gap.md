An earlier dirty revision-1 released run `runs/01a0dacf-d1b6-701f-ad69-647b4d6fc455/run-result.json` reported `startup-source-still-active` after 279 observed source starts and a thread increase from four to eight. The clean isolated Hackage 0.10.0.0 revision-2 run `runs/01a0e450-9ba5-7790-ad62-4155bea770f4/run-result.json` passed all 500 attempted offsets and 200 cycles, with four threads before and after. These run paths are local to this repository.

The source review and dirty probe support an intermittent historical ownership risk. A clean historical revision-2 run that reproduces it, or a deterministic fault-injection control, is still needed before assigning this suite's reproducible defect to an owner bug report. A passing timing sweep alone cannot disprove the source-level cancellation window.
