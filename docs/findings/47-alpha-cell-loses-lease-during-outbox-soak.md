# Alpha cell loses its lease during an outbox soak

Status: observed infrastructure interruption; attribution pending between the Kenshou lease client, GCS, and the cell's idle-stop path. No Keiro runtime or infrastructure-owner bug report is assigned without a reproducible cause.

The first clean released-cohort five-minute outbox soak on alpha was submitted as cell run `01a0f009-3f97-70dc-8dd4-110125fd01e0`, nested run `01a0eff2-31bc-76a6-8be7-27bf53309509`. The nested stderr reached measurement `done`, and the results bucket contains samples, series, diagnosis, and eight verdict files. It contains no nested `run-result.json` or manifest, so this is **not** a sealed Kenshou run and none of those partial verdicts is baseline evidence. The sealed cell result is `cancelled` with reasons `lease-lost` and `health-unavailable`; the orchestrator journal remains at `submitted` and cannot verify the slice.

At 2026-09-30 02:05:44 UTC, GCP recorded a `compute.instances.guestTerminate` operation for `cell-alpha-driver-0`. Immediately afterward the driver was terminated and monitoring was stopping while PostgreSQL remained running. The last cell health snapshot, ending 02:04:38 UTC, had no observations and tripped its availability gates. The control lease object had disappeared by inspection. These facts establish the infrastructure interruption, but do not identify which actor lost or removed the lease first.

Source inspection found that `Kenshou.Remote.Cell.Lease.withHeartbeat` marked a held lease lost after one failed renewal, without preserving the error in the session journal. The owner infrastructure's idle-stop script at `mori://shinzui/load-testing-infra` path `nixos/scripts/cell-idle-stop.sh` (artifact-level URI pending) powers off only when no live lease protects the machine and its inactivity threshold has elapsed. A transient renewal error followed by idle-stop is plausible, but unproved. Kenshou now retries a thrown renewal failure at one-second intervals until the last successful lease heartbeat's TTL plus grace expires, while a definitive fencing or cancellation result still ends the lease immediately. An injected one-failure test and all 105 remote-client examples pass; this validates the preventive client change, not the cause of this cell interruption. A same-seed five-minute retry used a twenty-minute lease and sealed and verified as cell run `01a0f014-6de1-70a5-bb0e-ee6a92a42336`; all eight outbox business checks held. This shows the scenario can complete under a longer lease, but does not identify the first attempt's failure path. The interrupted run remains excluded.
